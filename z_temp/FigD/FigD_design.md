# FigD：生成特征的三类评估

## 实验目的与公共设置

从下游注意力、特征分布及患者身份匹配三个层面，评估 MosaicSurv 根据可用模态重构 Gene 和 Clinic 特征的能力。真实模态特征为配对参照，重构特征为实验条件；两者使用同一患者及相同下游模型。

使用七个主线 TCGA 队列的完整病例，在测试时遮蔽指定模态。病理输入为冻结 UNI-v1，基因为 scFoundation cell_norm，临床为 L0。当前评估范围为主模型的第0折；热图每队列选择3名患者，分布及检索使用该折全部测试患者。

| 观察到的真实模态 | 被重构并与真实值比较的目标 |
|---|---|
| P | G'与G；C'与C |
| PC | G'与G |
| PG | C'与C |
| C | G'与G |
| G | C'与C |

共五种输入条件、六个重建方向，不重构病理图像。以下三项使用相同重构条件，但回答不同问题。

## 1. 下游注意力对照

对照组使用患者真实 Gene/Clinic 特征，实验组将目标模态替换为其重构特征。两组均输入同一个冻结 SurvPGC 模型，其他输入及病理 patch 保持一致。

比较两组在病理区域上的注意力热图，并展示 G'−G、C'−C 条件对应的注意力差分及高注意力 patch。该评估是定性的下游响应对照：注意力接近说明重构特征对该融合模型的响应相近，不等于证明病理区域具有因果解释。

## 2. 特征分布与配对位置

将同一目标模态的真实特征与生成特征联合降维，比较生成分布是否覆盖真实分布、是否过度集中，以及同患者生成点与真实点的位置差异。当前展示采用 UMAP；若实际采用其他降维方法，应按该方法解释。

| 指标 | 定义与用途 |
|---|---|
| 真实/生成样本数 | 分别报告真实特征库和测试患者生成特征数量 |
| 分散度比 | 二维生成坐标的平均标准差除以真实坐标的平均标准差；用于观察分布收缩 |
| 平均/中位配对距离 | 同患者生成点与真实点的二维欧氏距离，越小表示投影空间中更接近 |

降维方法、随机种子和真实库范围保持一致后才进行对照。二维重叠或较小配对距离不能直接证明原特征空间中的患者身份得到恢复。

## 3. 患者级检索

对每个测试患者，以生成的 G'或C'查询该队列全部可用的真实同模态特征，使用余弦相似度排序。正确匹配是该患者自身的真实特征，名次r从1开始；真实库大小记为N。

| 指标 | 定义 | 方向 |
|---|---|---|
| Top-1 | 正确匹配排第1的患者比例 | ↑ |
| Top-5 | 正确匹配进入前5的患者比例 | ↑ |
| MRR | 所有患者的1/r均值 | ↑ |
| Mean/Median rank | 正确匹配名次的均值/中位数 | ↓ |
| 平均百分位名次 | 100×(N−r+1)/N的均值 | ↑ |

随机排序参照分别为 Top-1=1/N、Top-5=min(5,N)/N、MRR=H_N/N、平均名次=(N+1)/2、平均百分位=50+50/N，H_N为前N项调和和。不同队列及目标模态的N可能不同，必须使用各自的随机基线。

检索是患者级身份匹配评估，分布图是群体表征评估，热图是下游响应评估。某项检索较弱不能直接推出生存预测无效；三项均不能替代独立的生存预测指标。
