# 模态缺失对比实验改装规格（执行 AI 用）

## 0. 定位与铁律

主模型为三模态 PoE-VAE 生存预测（Model_B）。本规格规定另外五个对比模型如何接入本仓库，以及主模型自身必须服从的统一约束。

1. **L3 机制本体禁止改动**。每个模型赖以成立的融合/缺失机制保持原实现，禁止替换等价实现、禁止"顺手优化"。(因此实际执行的时候最好是先迁移源代码，迁移完成之后再进行下述的对应修改)
2. **L0 与 L1 必须逐条统一**，不得有任何一个模型例外，主模型也不例外。
3. **L2 编码器不强制统一**，但必须披露。
4. 任何无法统一之处，在实现文件顶部的 `# DEVIATION:` 注释块和 `EXPERIMENT_NOTES.md` 中各记一次，禁止静默处理。
5. 第三方代码以 `third_party/<name>/` 原样保留，改装写在本仓库 wrapper 里。确需改第三方源码时用最小 patch，逐处记入 `third_party/<name>/PATCHES.md`。

---

## 1. 分层与统一范围

| 层 | 内容 | 统一要求 |
|---|---|---|
| L0 | split、折、缺失 mask、模态 dropout、生存头形式、cox loss、优化器、lr schedule、weight decay、early stopping、epoch 预算、batch size、评估口径 | 强制统一 |
| L1 | 冻结特征来源与形状 | 强制统一 |
| L2 | 各模态编码器（特征到模态级表示的那一段） | 不强制统一，强制披露 |
| L3 | 融合与缺失机制 | 自变量，不动 |

**`d_z = 128` 只约束 VAE 族**（主模型 / MVAE / MoPoE / 地板组）的共享隐维。HGCN 保留 `out_classes` 原默认宽度，Flex-MoE 保留 `hidden_dim` 与 `num_patches` 原默认。禁止把这两个模型压到 128。理由是宽度属于 L2，拉平等于用主模型的尺子量别人。

每个模型训练结束时必须向日志写一次可训练参数量（分 encoder / fusion / head 三部分统计）。

## 2. L1 特征口径

| 模态 | 来源 | 形状 | 说明 |
|---|---|---|---|
| WSI | UNI-v1 | `(n_patch, 1024)` | `n_patch` 逐病人变化 |
| Gene | scFoundation | `(4, 768)` | 固定 |
| Clinic | COACH L4 | `(n_c, 512)` | `n_c` 运行时从 `clinic_dir` 首个 `.pt` 读 `shape[0]`，禁止写死 |

全部为冻结预提取特征，任何模型不得微调特征提取器，不得引入除这三份之外的信息。

**coords 索引**：`.pt` 无 coords，只有 `.h5` 有。构建一个 `slide_id -> coords (N, 2)` 的索引，只被 HGCN 使用。必须从**与实际使用的特征同一套 patching 配置**的 h5 读取，加载时断言 `coords.shape[0] == features.shape[0]`，不等直接抛错终止，禁止截断或补齐。

## 3. L0 统一项

### 3.1 缺失来源唯一

dataloader 下发的 mask 是全项目唯一的缺失真值来源：

    avail: Dict[str, BoolTensor]   # {'wsi': (B,), 'gene': (B,), 'clinic': (B,)}
    # True = 该样本该模态可用；保证每个样本至少一个 True

每个模型只负责把 `avail` 翻译成自己的原生接口，**禁止反向修改 `avail` 语义**，**禁止在模型内部再生成一次缺失**。以下内部随机 masking 必须全部关闭或改为接收外部 mask：

- HGCN：`use_type` / `in_mask` 由 `avail` 驱动，其内部的模态随机 masking 关闭
- Flex-MoE：`batch_mcs` 由 `avail` 推出模态组合 id
- MVAE：`masks` 直接由 `avail` 转换；`use_subsampling` 保留开启，但 subset 只在 `avail` 为 True 的模态集合内枚举
- MoPoE：subset 枚举同上
- 主模型与地板组：模态 dropout 改为消费 `avail`，不自己采样

模态 dropout 的采样默认发生在 dataloader 层，主模型 / 地板组 / MVAE / MoPoE / Flex-MoE 共用同一份实现与同一个随机种子链。同一 fold 同一 epoch 同一样本，在这五个模型上缺的必须是同一批模态。

HGCN 单独走自己的图分支：训练 / 验证 / 测试可以使用独立的 loader / collate / mask 链，不强制和上面五个模型共享同一份缺失采样；但它仍然必须在自己的分支内保持可复现，且不能在模型内部再额外采样缺失。

### 3.2 统一生存头

    h (B, d_fuse) -> fuse_fc -> classifier -> Cox risk (B, 1)
    bag_loss = cox_surv, label_dim = 1

各模型自带的预测头一律换成上述形式。**唯一例外是 HGCN 的多分支结构，见 3.6。**

生成式模型（MVAE / MoPoE）总 loss = 原目标 + `λ_surv * L_cox`，`λ_surv = 1.0` 固定不调参。

### 3.3 训练与评估

- 优化器、lr scheduler、weight decay、early stopping 规则与主模型一致
- best checkpoint 从 `epoch >= 10` 起保存，`--max_epochs` 不低于 11
- split 复用 `splits/5foldcv/<study>/splits_*.csv`，不重新划分
- 日志键名、输出等等按照目前项目的模式来

### 3.4 路由

每个模型在"models"下建立的一个独立文件夹放 `Missing-modality baselines/`，接入 main.py 经 ` --modality <name>` 路由：
`survtri_poe_vae` / `mvae_poe` / `mopoe` / `flex_moe` / `hgcn` / `modality_concat`

## 4. 各模型改装规格

以下每节的"保留"部分逐条对应原实现，凡未列入"替换"或"适配"的，一律保持原样，包括所有超参默认值。**默认值不在本规格中重复列举，一律以原实现为准**；若因结构适配必须偏离某个默认值，写 `# DEVIATION:`。

### 4.2 concat 地板组

原设计里"统一 WSI 前端"与"禁止 attention pooling"两条互斥。按下面拆开，跑四种组合，共用一份代码。

**结构**

    WSI:    --concat_wsi meanpool  -> masked mean over valid patches -> (B, 1024)
            --concat_wsi resampler -> 与主模型同结构的 MIL Resampler（权重独立训练，
                                      不加载主模型权重）-> (B, K, 768) -> mean -> (B, 768)
    Gene:   flatten -> (B, 3072)
    Clinic: flatten -> (B, n_c * 512)

    x_m -[若该模态缺失，整条向量替换为 fill_m]-> MLP_m -> h_m (B, 128)
    h = concat(h_w, h_g, h_c) -> fuse_fc -> classifier -> risk

**保留（地板语义的构成要件，禁止放宽）**

- `MLP_m = Linear(D_m, d_z) -> ReLU -> Dropout -> Linear(d_z, d_z) -> ReLU`，最多两层，禁止加深
- 填充发生在 MLP **之前**的原始/池化特征空间。禁止"先过 MLP 再把输出置零"，带 bias 的线性层会把零输入映射成常数向量，等价于隐式可学习 missing token
- 禁止拼接缺失指示位、mask embedding、模态 ID
- 禁止对输入特征做逐维 z-score 标准化。若用 train mean 标准化，`zero` 与 `mean` 两组数值上等价，实验作废
- **LayerNorm 位置写死在第一个 Linear 之后**。放在填充与 Linear 之间会把 `zero` 和 `mean` 抹平

**填充规则**

- `--concat_impute zero`：`fill_m = zeros(D_m)`
- `--concat_impute mean`：`fill_m` = 该 fold **训练集上**该模态可用样本的池化特征均值。每折单独计算，只用 train split，训练开始前一次性算好，`register_buffer` 存入模型随 ckpt 保存，val/test 直接读 buffer，禁止推理时重算

`--concat_wsi {meanpool, resampler}` × `--concat_impute {zero, mean}` 四组全跑。`concat_rs` 系列是与主模型只差融合与填充的干净对照，`concat_mp` 系列保留最朴素参考值。

**参考资料**
这是现有的单模态模型实现，
models/model_single_clinic.py
models/model_single_gene.py
models/model_single_wsi.py
其中MIL层的层数供参考


### 4.3 MVAE（`mvae_poe`）

**保留不动**

- Product-of-Experts 联合后验，缺失时只乘可用专家 + 先验专家
- subset ELBO 目标（joint + unimodal + 随机 subset），`use_subsampling` 保持开启
- β warmup 的原实现
- `MultimodalBaseDataset` / `IncompleteDataset` 数据协议与 `masks` 语义

**必须替换**

- encoder 换成本项目投影 encoder：冻结特征 → `(B, 128)` 对角高斯后验，三模态各一份权重
- decoder 重建目标改为冻结特征本身，不是像素或原始 token
- 挂统一 Cox 头，总 loss = ELBO + `1.0 * L_cox`
- 跑本项目训练循环，不用 MultiVae 自带 trainer

**必须适配**

- `masks` 由 `avail` 转换；缺失模态在 `data[m]` 里填成同 shape 的零占位，这是框架的 shape contract 要求，不是补值语义
- subset 枚举限制在 `avail` 为 True 的模态集合内
- WSI 变长序列压成定长的方式：**与主模型完全一致**，复用主模型的 MIL Resampler 结构与 `wsi_target` 独立池化头（权重独立训练）

**必须记录**：MVAE 与主模型共用 encoder / decoder / 重建目标 / 生存头，差别只在聚合规则（vanilla PoE vs Generalized PoE）与散度形式（KL vs Jeffreys）。论文中不得作为"外部 MVAE 基线"呈现，必须放在聚合规则对照分组里，共享前端写进表注。

### 4.4 MoPoE（`mopoe`）

**保留不动**

- 先对每个非空模态子集做 PoE、再对所有子集后验做 MoE 的两级聚合
- `joint_elbo` 目标与其 mixture 权重聚合方式

**必须替换 / 适配**：与 4.3 **完全同一套** encoder / decoder / 重建目标 / 生存头。MoPoE 与 MVAE 之间的唯一差别必须只有模型类的选择，任何其他差别都是 bug。

**必须设置**：`modalities_specific_dim = None`，不启用模态私有 latent，避免比主模型多一块容量。

**必须适配**：只枚举当前样本 `avail` 为 True 的模态组成的 subset。


### 4.6 HGCN（`hgcn`）

**保留不动**

- 三套独立 `SAGEConv`（img / rna / cli，不共享权重）
- `my_GlobalAttention` 池化
- `PretrainVisionTransformer` 在线 MAE（模态级 token 上的遮盖重建，这是它的缺失机制）
- `MixerBlock`
- **`pool_x` 的 3 槽位语义**：`T = len(train_use_type) = 3`，缺失模态位置以零 `tmp_x` 进入槽位、由 MAE 重建后 broadcast 回节点特征图。禁止改成按可用模态数动态收缩
- **多分支输出与多分支 Cox**：`multi_x (3, 1)` 每模态一路风险、`one_x` 为其均值，`format_of_coxloss = multi`，三个模态的 cox loss factor 与 `mse_loss_of_mae` 及其系数全部保持原默认。缺失模态那一路的风险由 MAE 重建 token 导出，**必须照原路径计入 multi Cox**，这正是它的缺失机制在起作用的地方
- 8 邻域空间连边规则（coords 已确认存在）
- `out_classes`、`drop_out_ratio`、attention gate 网络结构保持原默认

**必须替换**

- 节点特征来源换成本项目冻结特征：`x_img = (N_img, 1024)`、`x_rna = (4, 768)`、`x_cli = (n_c, 512)`
- 三个 `SAGEConv` 的 `in_channels` 分别改为 1024 / 768 / 512。**禁止零填充到 1024**：原版补零是为兼容极低维模态的写法，不携带设计意图，三套 conv 参数独立，改 `in_channels` 是更小的偏离
- 末端只统一 `one_x` 那一路 risk 的输出形式（对齐 `fuse_fc -> classifier -> risk`）。**禁止把 `multi_x` 压成单分支**

**必须适配**

- WSI 边：从 coords 索引取 `(N_img, 2)`，按 8 邻域连边。加载时断言 `coords.shape[0] == n_patch`
从 .h5 读出 features + coords，再构图后封成 Data。
其他模型使用的WSI编码数据为SurvPGC_Workspace/{数据集}/P/uni_v1；
该模型使用SurvPGC_Workspace/{数据集}/P/uni_v1_h5，其中WSI地址的参数还是一样的，但是只是该模型隐含指向同级目录下的_h5后缀文件夹。
- Gene 边：4 节点去自环全连接，`edge_index` 为 `[2, 12]`（原版 5 节点为 `[2, 20]`）
- Clinic 边：`n_c` 节点去自环全连接，`[2, n_c*(n_c-1)]`（原版 10 节点为 `[2, 90]`）
- `use_type` / `in_mask` 由 `avail` 驱动，`train_use_type` 恒为三模态全集

## 5. 数据管线分叉

总之一份 canonical patient-level 记录，但是有两条 collate 路径：

- **稠密路径**（主模型 / 地板组 / MVAE / MoPoE / Flex-MoE）：WSI padding + `padding_mask`，gene / clinic 直接堆叠
- **图路径**（HGCN）：PyG `Data` + `Batch`

除了 HGCN与 Flex-MoE 之外的模型 模型消费**同一份 `avail` mask 文件**，同一 fold 同一 epoch 同一样本的缺失模态必须完全一致。HGCN 与 Flex-MoE 走独立的分支，可不参与这条共享链，但必须在自己的 loader 内保持一致性。

## 6. 偏离登记表

在 创建的文件夹下创建修改说明`EXPERIMENT_NOTES.md` 中维护，每条含：模型、偏离项（适配替换与修改）、原实现是什么、改成了什么、理由（指南中说明/自己改动+具体理由）。当前已知必须登记的：

| 模型 | 适配、替换与修改 |
|---|---|
| 全体 | 编码器不统一（L2），改为披露参数量 |
| 前五个模型 | 各模型内部随机 masking 关闭，改由统一 mask 驱动 |
| HGCN | 独立图分支，不与前五个模型共享同一份 mask 采样链；保留原生 batch 语义 |
| MVAE / MoPoE | 与主模型共享前端与重建目标，实为聚合规则消融 |
| MVAE / MoPoE | 原生 encoder/decoder 与生成式下游被替换 |
| Flex-MoE | `Custom3DCNN` 删除；WSI 经 masked mean pooling 降为定长；分类头换 Cox |
| HGCN | `SAGEConv` in_channels 按模态改动，未沿用零填充；节点语义漂移；末端 `one_x` 输出形式统一；独立分支批处理 |
| 地板组 | `concat_rs` 使用与主模型同结构的 resampler，非原始地板设定 |

## 7. 交付检查表

按顺序完成，每项通过后再进下一项：

1. `avail` 生成器 + 两条 collate 路径一致性断言通过
2. HGCN 独立分支的 batch 组织、WSI通道 pipeline（含 coords 索引建立，`coords.shape[0] == n_patch`）全量断言通过
3. 偏离登记表
4. 六个模型各输出一次参数量统计
5. 给一个对应的 main.py 入口的测试命令，并且作为 test_instruction.md 输出对应文件夹中。
