# 诊断：主模型在 Table4 消融中"优势消失"的原因排查

日期：2026-10-06。范围：仅用已有结果与 git 历史，未重训。

## 结论先行

1. **消融变体的参数确实被大改了**，但不是"变体单独被调强"——是**整个 Table4 批次换了参数点**：
   旧批次跑在 T4 行 `t025_alpha_learn` / `t028_alpha_learn`（与旧官方点 t015 完全不同的另一套参数），
   新批次统一跑 t018。**旧批次连当时的官方点 t015 都没用上，旧实验本身是不公平、不完善的（与你的判断一致）。**
2. **代码/pipeline 没有功能性改动**：48552bb → HEAD 的所有模型代码、预设、分发逻辑均为
   Cfilm→MosaicSurv 纯改名（逐文件 diff 验证，见下）；唯一实质改动是基类里 A/B 变体的
   崩溃兜底（不影响 C 组，且 B 组现在仍大幅落后，可见不是它抬高了变体）。
3. **当前"变体反超"在噪声范围内**：A/C 组差距 0.002–0.006（均值）/ ≤0.03（单数据集），
   全部远小于 fold 波动（std 0.03–0.08）；且 val==test 无独立测试集，任何零点几百分点的
   "优势"都不构成统计结论。**B 组（twostage/frozen）与 detached 仍大幅落后主模型
   （差距 0.08–0.11，远超波动）——消融实验的核心结论依然成立。**
4. 主模型自身 t015→t018：Table1 均值 0.7355→0.7260（噪声级小降），但 Table2（缺失模态）
   rank10→rank1、Table3（缺失率）rank3→rank2——**t018 是缺失模态场景下明显更优的点**，
   这正是当时选 t018 的依据。

## 二、代码/pipeline 是否被改动（用户优先级第一的问题）

`git diff 48552bb HEAD` 逐文件结论：

| 文件 | 改动 | 性质 |
|---|---|---|
| `models/ablation_models/model_C_film.py → model_mosaic_surv.py` | 4 行 | 纯改名（类名 + docstring） |
| `model_C_film_kl.py → model_mosaic_surv_kl.py` | 4 行 | 纯改名，基类不变（SurvTriPoEVAE_KL） |
| `model_C_film_surv0.py → model_mosaic_surv_detached.py` | 6 行 | 纯改名，`surv_detach_poe=True` 语义不变 |
| `model_C_film_noenum.py → model_mosaic_surv_noenum.py` | 9 行 | 纯改名，`uses_multi_pattern_surv=False` 不变 |
| `model_C_single.py / _single_enum / _multi / A_film / B_film` | **0 行** | 变体类文件完全未动 |
| `models/model_SurvTriPoEVAE.py` | +7 行 | **唯一实质改动**：`n_patterns==0` 时 A/B 变体退化到 pattern-7 兜底防崩溃（见下） |
| `configs/presets.sh` | 44 行 | 纯改名，参数值、`POE_BETA_TARGET=0` 覆盖逻辑不变 |
| `utils/core_utils.py / process_args.py / main.py` | 改名映射 | modality 名与类分发映射改名，无功能变化 |
| `configs/z_exp_gen/Table4_Abaltion_Test/_common.bash` | 改名 | CFILM_*→MOSAIC_* 变量改名，生成逻辑不变 |

唯一实质改动（`models/model_SurvTriPoEVAE.py:314`）：epoch 末 batch 样本不足导致
`n_patterns==0` 时，**A/B 变体**（损失只含 survival 项）会零梯度崩溃，新增 pattern-7 兜底。
这只会影响 A/B 变体（frozen/twostage），且它们现在仍大幅落后主模型（B 组 0.6383/0.6423），
因此**不是变体性能上升的原因**。

> 结论：**pipeline 与模型代码没有功能性改动。变体表现变化完全来自参数点改变
> （整批 t025/t028 → t018），与"变体被偷偷调强"无关。**

## 四、整体归因

1. **旧优势的性质**：旧 Table4 在 t025/t028（低 dropout 0.05、BETAFIX=true、lambda 0.1、
   beta 1.0/0.1）下训练，这套参数与主模型官方点 t015 无关，且主模型在这两点上本身就不强。
   旧实验连"官方点下的消融"都不是——**不公平、不完善，与你的判断一致**。其数值已删，
   无法复核"旧优势"的具体幅度，但即便真实，也不构成对现行结论的反驳。
2. **新批次发生了什么**：全部 10 个 preset 统一 t018，这是一次口径正确的重跑。
   结果：A/C 组变体与主模型打成噪声级并列，B 组与 detached 仍大幅落后。
   主模型在 t018 下没有"变差"到统计显著的程度（Table1 −0.0095，噪声内），
   而 t018 换来缺失模态场景的 rank1/rank2。
3. **方法学提醒（写论文必须考虑）**：splits 中 val==test（`splits/5foldcv/*/splits_*.csv`
   的 test 列与 val 相同），所有"优势/反超"都在模型选择集上测量，零点几百分点的差距
   一律视为并列；fold std 0.03–0.08 是判定差异的底线。若论文需要 A/C 组的分出胜负，
   必须多种子平均（2–3 seeds），否则只能如实报告"并列"。

## 五、决策选项（供拍板）

- **A. 保持 t018，如实呈现（推荐，零额外成本）**：A/C 组报告为噪声级并列；
  强调 B 组（联合训练 vs 两阶段/冻结，−0.08）与 detached（L_surv 回传，−0.11）的显著
  消融结论；Table1 主模型仍 rank1（0.7266），Table2/3 缺失模态优势是 t018 的核心卖点。
- **B. 回滚 t015**：Table1 均值 +0.0095（噪声内），但 Table2 从 rank1 掉到 rank10——
  以缺失模态为卖点的论文会明显受损；且 Table1-4 全部要重跑，不推荐。
- **C. 重跑旧点（t025/t028）Table4 复现"旧优势"**：需要重训，且结果与论文官方点不一致，
  等于承认用两套参数讲故事，审稿风险高，不推荐。
- **D. 多种子平均（2–3 seeds）重跑 Table4 A/C 组**：唯一能真正把 A/C 组差距稳定下来的
  手段（记忆 [[cfilm-hparam-retest-variance]]：单种子排名不可复现是已证实的现象），
  需要 GPU 时间，本次未执行，可作为后续。
