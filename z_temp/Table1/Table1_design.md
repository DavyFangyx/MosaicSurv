# Table1：完整模态生存预测对比

## 实验目的

检验 MosaicSurv 在三模态完整条件下的生存排序、预测误差和时间依赖判别能力，并与单模态、双模态和三模态方法比较。

## 实验组与对照组

P、G、C 分别表示病理、基因和临床模态。所有方法按患者使用相同的五折划分，在 BRCA、COAD、KIRC、KIRP、LIHC、LUAD、LUSC 七个队列分别评估。

| 组别 | 方法 | 输入 | 对照目的 |
|---|---|---|---|
| 单模态 | ABMIL、TransMIL | P | 病理表征与聚合方法对照 |
| 单模态 | MLP、SNN | C | 临床特征独立预测能力；特征展平后输入 |
| 单模态 | MLP、SNN | G | 基因特征独立预测能力 |
| 双模态 | SurvPC | P+C | 病理与临床融合 |
| 双模态 | PORPOISE、SurvPath、MCAT | P+G | 病理与基因融合 |
| 双模态 | SurvGC | C+G | 无病理条件的双模态融合 |
| 三模态对照 | SurvPGC、HGCN | P+C+G | 完整信息下的融合方法对照 |
| 实验组 | MosaicSurv | P+C+G | PoE-VAE 共享隐空间、FiLM 条件化读出与联合生存学习 |

共 14 个模型。常规模型使用冻结 UNI-v1 病理特征、scFoundation cell_norm 基因特征和 L0 临床 prompt 特征；HGCN 使用原生 KimiaNet、GSEA 和临床图特征，属于输入表征例外，不宣称所有方法输入完全相同。

MosaicSurv 隐变量及读出隐藏维度均为128，解码器隐藏维度512；学习率0.001、权重衰减0.0001、batch size 16，联合训练20轮。生存损失权重1，Jeffreys 正则目标权重0.1，训练期模态 dropout 概率0.35，PoE 模态权重可学习。基线保留各自预测结构和训练目标，不强制改造成同一种生存头。

## 评估指标

| 指标 | 含义与方向 |
|---|---|
| C-index ↑ | 可比较患者对中的生存风险排序一致性 |
| IBS ↓ | 随时间积分的生存概率预测误差，使用删失校正 |
| 2年/5年时间依赖 AUC ↑ | 指定时间点的生存判别能力 |
| 平均排名 ↓ | 每个队列按平均 C-index 排名，再对七队列取平均；并列采用平均名次 |
| 与实验组的 p 值 | 按同队列、同折的 C-index 配对，使用 Wilcoxon 检验并进行 Holm 多重比较校正 |

每个队列的指标报告五折均值与标准差；跨队列均值不按患者数加权。缺少有效随访或事件支持的时间点应保留不可估状态。既有附录中若列名标注“3y”，该列是3年 AUC，不能解释为5年结果。

## 解释边界

五折标准差反映折间波动，不是患者抽样置信区间。既有数据划分中验证集与测试集重合，模型选择和显著性解释需披露这一限制。Table1 与 Table4 的主模型来自不同训练批次，结果分别用于各自对照。
