### FigC_KM_curves — Kaplan-Meier 生存曲线

- 生成：`python results_display/scripts/FigC_KM_curves.py --test-dir L0Test --dataset {BRCA,...|all} [--annotate-hr]`
- 分组：折内中位数二分（fold-median split；cox 线性预测子跨折不可比，每折在各自中位数处二分后合并）；
  HR + 95% CI 由脚本内自实现 Efron Cox（`coxph_efron`，与 R coxph / lifelines ties="efron" 一致）计算，
  log-rank p 同图标注
- 产出：`FigC_KM_curves/<test-dir>/<dataset>/all_models.png|pdf` + `per_model/{model}.png` + `km_stats.csv`；
  顶层 `km_hr_matrix.csv`（行=模型，列=各数据集 `HR (CI) | p` + Mean HR）
- 现状：L0Test 已出 BRCA / COAD / KIRC / KIRP / LIHC 5 数据集；LUAD / LUSC 待其 Table1 批次完成后补跑

### FigD_Generated_Heatmaps — 生成特征可视化（热图 / embedding / 检索）

- 生成：三脚本共用一个输出目录
  - `FigD_Generated_Heatmaps.py` — GT vs PoE 重构特征的 SurvPGC_F attention 热图
  - `FigD_Generated_Embedding.py` — 跨模态 embedding 对齐 overlay
  - `FigD_Generated_Retrieval.py` — 跨模态检索
- 输出：`FigD_Generated_Heatmaps/<dataset>/fold<k>/<poe_model>/{attention,embedding,retrieval}/`
  - attention：左=原始模态注意力 / 右=生成模态注意力，下方 5 个最高注意力 patch（jet 色图）；
    另存独立差分热图 G'-G / C'-C（发散色图居中 0）；对比子集：P→(G/G'、C/C')、PC→G/G'、PG→C/C'、C→G/G'、G→C/C'
  - embedding：`embedding_overlay_summary.csv` + meta；retrieval：`retrieval_summary.png` + ranks/summary
- checkpoint：主模型取 Table1_Cindex_Main/<test-dir>，消融变体取 Table4_Abaltion_Test
- 现状：仅 LIHC / fold0 已产出
